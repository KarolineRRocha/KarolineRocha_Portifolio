## 📱 Screenshot Guidelines

### **Quality Standards**
- **Resolution**: High quality (2x for retina displays)
- **Format**: PNG with transparency support
- **Compression**: Optimized for web (under 500KB each)
- **Consistency**: Same browser and theme across all screenshots

### **Browser Settings**
- **Browser**: Chrome or Firefox (latest version)
- **Theme**: Light mode
- **Zoom**: 100% (default)
- **Window**: Full browser window

### **Content Guidelines**
- **No sensitive data**: Remove any personal information
- **Professional appearance**: Clean, uncluttered interface
- **Highlight features**: Focus on key functionality
- **Consistent styling**: Use the same design theme

## 🛠️ Taking Screenshots

### **Desktop Screenshots**
1. Open the application in a modern browser
2. Set browser window to 1200x800px
3. Navigate to the specific page/section
4. Take screenshot using browser dev tools or system screenshot tool
5. Crop and optimize the image

### **Mobile Screenshots**
1. Use browser dev tools mobile emulation
2. Set device to iPhone SE (375x667px)
3. Navigate to the specific page/section
4. Take screenshot and save as PNG

### **Optimization**
1. Use tools like TinyPNG or ImageOptim
2. Maintain quality while reducing file size
3. Ensure transparency is preserved where needed
4. Test that images load quickly on GitHub

## 📁 File Naming Convention

- Use kebab-case: `home-hero.png`
- Include descriptive names: `mobile-navigation.png`
- Add size suffix if needed: `projects-section-desktop.png`

## 🔄 Updating Screenshots

When updating screenshots:
1. Take new screenshots following the guidelines
2. Optimize and compress the images
3. Update the main README.md with new image references
4. Commit changes with descriptive commit message
